# Архитектура сервиса

Сервис состоит из нескольких независимых компонентов, которые обмениваются
сообщениями через очередь. Такое разделение позволяет масштабировать каждый
элемент отдельно и упрощает сопровождение.

## Компоненты

Приёмник запросов принимает входящие данные, проверяет их формат и передаёт
дальше. Обработчик выполняет основную логику. Хранилище отвечает за
долговременное сохранение и поиск.

## Потоки данных

Каждый запрос проходит последовательность этапов. Сначала выполняется
проверка подлинности, затем маршрутизация, затем обработка и, наконец,
запись результата. Ошибки на любом этапе приводят к повторной попытке.

## Наблюдаемость

Все компоненты публикуют метрики и трассировки. Собранные данные помогают
быстро находить узкие места и разбирать инциденты.
