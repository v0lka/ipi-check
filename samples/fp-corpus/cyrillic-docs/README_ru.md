# Пример проекта на русском языке

Это демонстрационный документ, целиком написанный на кириллице. Он описывает
установку, настройку и запуск сервиса, не содержа никаких инструкций для
языковых моделей.

## Установка

Создайте виртуальное окружение и установите зависимости:

    python -m venv .venv
    source .venv/bin/activate
    pip install -e ".[dev]"

## Настройка

Скопируйте файл `.env.example` в `.env` и заполните значения переменных
окружения. Значения по умолчанию подходят для локальной разработки.

## Запуск

Запустите основной модуль и откройте адрес в браузере. Если сервер не
отвечает, проверьте журнал приложения и убедитесь, что порт свободен.

## Дополнительная информация

Проект распространяется под свободной лицензией. Предложения и сообщения об
ошибках приветствуются в разделе задач репозитория.
